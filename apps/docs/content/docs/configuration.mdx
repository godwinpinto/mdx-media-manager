title: Configuration
description: All options, with their defaults.
---

Most projects need no options. Pass them as the second argument of `withMdxMediaManager` (Next.js)
or to `mdxMediaManager()` (Vite):

<Tabs items={['Next.js', 'Vite']}>
<Tab value="Next.js">

```js title="next.config.mjs"
// inside the helper that `init` wrote
return withMdxMediaManager(input, {
  image: { format: 'avif', quality: 70 },
})(phase, context);
```

</Tab>
<Tab value="Vite">

```ts title="vite.config.ts"
mdxMediaManager({
  image: { format: 'avif', quality: 70 },
});
```

</Tab>
</Tabs>

## Options

<TypeTable
  type={{
    contentDir: {
      description: 'Folder with your MDX content, relative to `root`. Image folders are named after a page\'s path inside it.',

      description: 'Static folder served at `/`, relative to `root`.',
      type: 'string',
      default: "'public'",
    },
    imagesDir: {
      description: 'Folder inside `publicDir` that images are saved to.',
      type: 'string',
      default: "'images'",
    },
    image: {
      description: 'Default output for processed images. The dialog can change them per upload.',
      type: "{ format?: 'webp' | 'avif' | 'png' | 'jpeg'; quality?: number; maxWidth?: number }",

    maxUploadSize: {
      description: 'Largest accepted upload, in bytes.',

    pageUrl: {
      description: 'URL a content file is served at (path relative to `root`), for "Open" links in the library. Return `undefined` to use the default.',

    },
    s3: {
      description: 'Store images in S3 and reference them by CDN URL. `false` turns it off even when the environment variables are set.',
      type: 'S3Options | false',
      default: 'read from MDX_MEDIA_* environment variables',
      typeDescriptionLink: '#s3-options',
    },
    allowedHosts: {
      description: 'Hostnames allowed to use the API, besides localhost, 127.0.0.1 and ::1 (for example a LAN name).',
      type: 'string[]',
      default: '[]',
    },
    basePath: {
      description: 'URL prefix of the API.',
      type: 'string',
      default: "'/__mdx-media'",
    },
    root: {
      description: 'Project root containing your content and public folder.',
      type: 'string',
      default: 'process.cwd() (Vite: the Vite root)',
    },
    env: {
      description: 'Environment to read MDX_MEDIA_* variables from.',
      type: 'Record<string, string | undefined>',

    },

## S3 options

Usually set through [environment variables](/docs/environment-variables); see
[S3 and CDN](/docs/s3).
